# Arusuvai E-Commerce Grocery Website

Arusuvai is a responsive e-commerce grocery website developed using HTML, CSS, and JavaScript. The website provides an attractive and user-friendly platform for customers to browse and purchase grocery products online.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and intuitive user interface
- Product listing and categorization
- Shopping cart functionality
- Interactive navigation menu
- Featured products section
- Promotional banners and offers
- Fast and smooth user experience

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
